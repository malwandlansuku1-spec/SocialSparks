# SocialSpark
Social Sparks – Android Application

1. Introduction

Social Sparks is a native Android application developed using Kotlin. The purpose of the app is to help users maintain social connections by suggesting simple social activities based on the time of day.

2. Objectives

The main objective is to make social interaction easier by providing useful suggestions for morning, afternoon and evening.

3. App Features

- Time of day input.
- Social interaction suggestions.
- Reset button.
- Input validation and error messages.
- Simple and user-friendly interface.

4. Technologies Used

- Kotlin
- Android Studio
- GitHub
- GitHub Actions

5. Social Spark Suggestions

- Morning: Send a good morning message.
- Mid-morning: Send a thank-you message.
- Afternoon: Share something interesting with a friend.
- Afternoon snack time: Send a thinking-of-you message.
- Dinner: Call a friend or relative.
- After dinner/night: Leave a thoughtful comment on a friend's post.

6. Testing

The application will be tested using different time inputs to check that the correct suggestions are displayed. Invalid inputs will also be tested.

7. GitHub and Automation

GitHub will be used to store and manage the source code. GitHub Actions will be configured to automate the Android build and testing process.
